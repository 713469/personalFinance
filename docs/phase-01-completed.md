# 阶段一：项目初始化与基础闭环

## 已完成任务

- 创建前端 Vue 3 项目与后端 Spring Boot 项目骨架。
- 接入 MySQL、MyBatis-Plus，并完成基础数据库初始化脚本。
- 关闭 Lombok 依赖，统一使用显式代码结构。
- 配置 Docker Compose，本地可一键拉起前端、后端和数据库。
- 选择并固定了偏僻端口，减少与本地其他项目的冲突。
- 完成前后端基础联调，接口可以读取并写入真实数据。
- 将首页、账单、分类、账户等页面接入真实后端数据。
- 完成快速新增弹窗能力，支持新增账单、分类、账户。
- 增加基础交互动效，如页面切换、按钮点击反馈等。
- 完成项目文件结构的初步整理，分离 shared、pages、layouts、api、store 等职责。

## 备注

- 本阶段重点是先跑通真实业务闭环，后续阶段再继续细化筛选、视觉一致性和可维护性。
